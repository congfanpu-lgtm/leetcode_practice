灵山茶艾府
```python
class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        # l r
        #[1, r] [l+1, r] ... [r,r]
        #r - l + 1 以r为右端点的集合个数

        if k <= 1:
            return 0
        ans = 0
        prod = 1
        left = 0

        for right,x in enumerate(nums):
            prod *= x
            while prod >= k:
                prod /= nums[left]
                left += 1
            ans += right -left + 1  

        return ans
```
**思路**：
1. 寻找一个小于k的区间内的子区间个数的数学公式
2. 再之后便可以转化为209题
