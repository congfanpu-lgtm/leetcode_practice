灵山
写法一：哈希表（整型数组）
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        ans = left = 0
        d = defaultdict(int)
        for right,c in enumerate(s):
            d[c] += 1
            while d[c] > 1:
                d[s[left]] -= 1
                left += 1
            ans = max(ans, right - left + 1)
        return ans
```
一样的：
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        ## 时间复杂度O(n)
        ## 空间复杂度O(128)

        ans = 0
        cnt = Counter()
        left = 0
        
        for right,c in enumerate(s):
            cnt[c] += 1
            while cnt[c] > 1:    
                cnt[s[left]] -= 1
                left += 1
            ans = max(ans, right - left + 1)
        return ans
```
**注意**：
1.  哈希表（Counter）的查找操作是 O(1)
2. 注意是 cnt[s[left]] -= 1
