## 参考答案：
---
做法一：回溯
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        def dfs(i):
            if i < 0:
                return 0
            res = max(dfs(i-1), dfs(i-2) + nums[i])
            return res
        return dfs(n-1)
```
**注意**：
1. 回溯时间复杂度是指数级别，因此会超时

做法二：回溯+ cache
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        cache = [-1] * n
        def dfs(i):
            if i < 0:
                return 0
            if cache[i] != -1:
                return cache[i]
            res = max(dfs(i-1), dfs(i-2) + nums[i])
            cache[i] = res
            return res
        return dfs(n-1)
```
**注意**:
1. 时间复杂度是O(n)，通过状态个数* 单个状态所需要的时间，状态个数是O(n)，单个状态的计算时间是O(1)，所以时间复杂度是O(n)
2. 空间复杂度也是O(n)

做法三：递推
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        f = [0] * (n+2)
        for i,x in enumerate(nums):
            f[i+2] = max(f[i+1], f[i] + x)
        return f[n+1]
```
**注意**：
1.  时间复杂度是O(n)，空间复杂度也是O(n)

做法四：递推+优化空间复杂度
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        f0 = f1 = 0
        for i,x in enumerate(nums):
            new_f = max(f1, f0 + x)
            f0 = f1
            f1 = new_f
        return f1
```
注意：
1.  时间复杂度是O(n)，空间复杂度是O(1)
