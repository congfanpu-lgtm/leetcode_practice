```python
def lower_bound(nums: List[int]) -> int:
    left = 0
    right = len(nums) -2
    while left <= right:
        mid = (left + right ) // 2
        if nums[mid] < nums[mid + 1]:
            left = mid + 1
        else:
            right = mid - 1
    return left
  
class Solution:
    def findPeakElement(self, nums: List[int]) -> int:
        index = lower_bound(nums)
        return index
```
**思路**：
1. 二分法夹逼法查找一个最大值，因为最大值为不会和临近数相等，所以可以使用二分法夹逼
