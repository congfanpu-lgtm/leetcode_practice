## 参考答案：
---
```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        ans = [0] * n
        st = []
        for i in range(n-1,-1,-1):
            t = temperatures[i]
            while st and t >= temperatures[st[-1]]: #当st为空时，直接跳过
                st.pop()
            if st:   #当st为空时，直接跳过，ans[i] = 0,因为一开始的初始化
                ans[i] = st[-1] - i
            st.append(i)
        return ans
```
时间复杂度O(n)，空间复杂度O(min(n,U)) U=max-min+1
