## 参考答案：
---
```python
# Definition for singly-linked list.

# class ListNode:

#     def __init__(self, val=0, next=None):

#         self.val = val

#         self.next = next

class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        n = 0
        cur = head
        while cur:
            n += 1
            cur = cur.next
        dummy = ListNode(next = head)
        p0 = dummy

        while n >= k:
            n -= k
            pre = None
            cur = p0.next
            for _ in range(k):
                nxt = cur.next
                cur.next = pre
                pre = cur
                cur = nxt
            nxt = p0.next ##next:反转前的组头
            p0.next.next = cur
            p0.next = pre 
            p0 = nxt ##p0:指向当前组的前一个节点
        return dummy.next
```
**注意**：
倒数四步的理解：
```python
            nxt = p0.next ##next:反转前的组头
            p0.next.next = cur
            p0.next = pre 
            p0 = nxt ##p0:指向当前组的前一个节点
```
1. nxt：记录当前组在未翻转前 组中的第一个节点（反转后最后一个节点） 在解析中对应 1 号节点
2. p0.next.next = cur：nxt 的下一个节点指向cur 因为翻转前的组头相当于反转后的尾巴，即尾巴连接下一组的组头
3. p0.next = pre： p0的下一个节点指向pre，pre是当前组内翻转后的第一个节点，即上一组的最后一个节点连接这一组的第一个节点
4. 把当前组的最后一个节点定为p0，作为下一组的哨兵节点

==**个人理解后三步思路（环环相扣）==：**
1. 一开始翻转完，1指向空，所以率先调整1的指向
2. 调整完1的指向之后就可以调整哨兵节点的指向，因为不然的话调整完哨兵的指向，会影响对组内最后一个节点（1）的定位
3. 把当前组内的哨兵的指向也调整完之后，可以将p0 修改为下一个组所需要的哨兵节点
