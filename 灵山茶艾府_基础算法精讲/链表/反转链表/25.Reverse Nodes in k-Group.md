## 参考答案：
---
```python
# Definition for singly-linked list.

# class ListNode:

#     def __init__(self, val=0, next=None):

#         self.val = val

#         self.next = next

class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        n = 0
        cur = head
        while cur:
            n += 1
            cur = cur.next
        dummy = ListNode(next = head)
        p0 = dummy

        while n >= k:
            n -= k
            pre = None
            cur = p0.next
            for _ in range(k):
                nxt = cur.next
                cur.next = pre
                pre = cur
                cur = nxt
            nxt = p0.next ##next:反转前的组头
            p0.next.next = cur
            p0.next = pre 
            p0 = nxt ##p0:指向当前组的前一个节点
        return dummy.next
```
**注意**：
1. nxt：记录当前组在未翻转前 组中的第一个节点 在解析中对应 1 号节点
2. p0.next.next = cur：nxt 的下一个节点指向cur 因为翻转前的组头相当于反转后的尾巴，即尾巴连接下一组的组头
3. p0.next = pre： p0的下一个节点指向pre，pre是当前组内翻转后的第一个节点，即上一组的最后一个节点连接这一组的第一个节点
