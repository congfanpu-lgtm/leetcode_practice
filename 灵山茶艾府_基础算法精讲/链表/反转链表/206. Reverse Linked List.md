## 参考答案：
---
灵山：
```python
# Definition for singly-linked list.

# class ListNode:

#     def __init__(self, val=0, next=None):

#         self.val = val

#         self.next = next

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        pre = None
        cur = head

        while cur:
            nxt = cur.next
            cur.next = pre
            pre = cur
            cur = nxt
        return pre
```
**注意**：翻转后，原来的head已经被改变了
```
翻转前：
head → [1|·]→ [2|·]→ [3|/]

翻转后：
head ---↓
       [1|/]  ← [2|·]  ← [3|/]
                         ↑
                        pre
```

链表的每个节点包含节点值和指向下一个节点的next指针，链表的最后一个节点指向空
如果要反转链表，则链表的原本的第一个节点指向空，把当前节点的next修改成上一个节点
![](assets/206.%20Reverse%20Linked%20List/file-20260118190620073.png)
需要nxt变量来记录当前节点原来的next是谁
![](assets/206.%20Reverse%20Linked%20List/file-20260118190620071.png)
把原本的pre修改为cur，把cur变量修改为当前的next
