## 参考答案：
---
```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        m = n * 2
        ans = []
        path = [''] * m
        def dfs(i, open):
            if i == m:
                ans.append(''.join(path))
                return
                
            if open < n:
                path[i] = '('
                dfs(i+1, open + 1)
                
            if i - open < open:
                path[i] = ')'
                dfs(i+1, open)
        dfs(0, 0)
        return ans
```

1. 感觉用选或不选的方法，思路比较清晰
