## 参考答案：

```python
class Solution
    def combinationSum3(self, k: int, n: int) -> List[List[int]]:
        ans = []
        path = []
        # O(k*c(9,k))
        def dfs(i, t):
            d = k - len(path)
            if t < 0 or t > (i * 2 - d + 1)*d // 2:
                return
            if len(path) == k:
                ans.append(path.copy())
                return
            for j in range(i, d-1, -1):
                path.append(j)
                dfs(j-1, t-j)
                path.pop()
        dfs(9, n)
        return ans
```
**注意**：
1. 判断t是否小于0 并且 是否大于剩下的最大数相加，如果是则直接return
2. 当d = 0时，t !>0 and t !<0 因此 t == 0 不需要额外判断
