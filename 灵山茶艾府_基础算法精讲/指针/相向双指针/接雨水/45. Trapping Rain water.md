灵山茶艾府：
解法一：需要两个数组，时间复杂度O(n)，空间复杂度O(n)
自己的代码：
```python
##根据提供的思路，自己编写的代码：
class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        maxh = 0
        amount = 0
        arr1 = list(range(n))
        arr2 = list(range(n))
        
        for i in range(n): ##左最大
            maxh = max(maxh,height[i])
            arr1[i] = maxh
        ##右最大
        maxh = 0 
        for j in range(n-1,-1,-1):
            maxh = max(maxh,height[j])
            arr2[j] = maxh
        ##合并
        arr3 = list(range(n))
        for k in range(n):
            arr3[k] = min(arr1[k],arr2[k])
        ##遍历计算
        for m in range(n):
            add = arr3[m] - height[m] if arr3[m] > height[m] else 0
            amount += add

        return amount
```
灵神的代码：
```python

class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        pre_max = [0] * n
        pre_max[0] = height[0]
        for i in range(1, n):
            pre_max[i] = max(pre_max[i-1], height[i])
            
        suf_max = [0] * n
        suf_max[-1] = height[-1]
        for i in range(n-2, -1, -1):
            suf_max[i] = max(suf_max[i+1], height[i])
            
        ans = 0
        for h, pre, suf in zip(height, pre_max, suf_max):
            ans += min(pre,suf) - h
        return ans
```

解法二：时间复杂度O(n)，空间复杂度O(1)
```python
class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        ans = 0
        left = 0
        right = n - 1
        pre_max = 0
        suf_max = 0

        while left <= right:
            pre_max = max(pre_max, height[left])
            suf_max = max(suf_max, height[right])

            if pre_max < suf_max:
                ans += pre_max - height[left]
                left += 1
            else:
                ans += suf_max - height[right]
                right -= 1
        return ans
```

**考点**：
1. 注意用两边夹的方式，真的很巧妙
2. 同时可以边移动指针边计算接雨水的量
