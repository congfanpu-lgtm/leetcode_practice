## 参考答案：
---
**前序遍历**：
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isValidBST(self, root: Optional[TreeNode],left = -inf, right = inf) -> bool:
        if root is None:
            return True
        x = root.val
        return left < x < right and self.isValidBST(root.left,left,x) and self.isValidBST(root.right,x,right)
```
**注意**：return既要判断当前节点，也要去判断左右子节点

**中序遍历**：
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    pre = -inf
    def isValidBST(self, root: Optional[TreeNode],left = -inf, right = inf) -> bool:
        if root is None:
            return True
        if not self.isValidBST(root.left):
            return False
        if root.val <= self.pre:
            return False
        self.pre = root.val
        return self.isValidBST(root.right)
```

**后序遍历**：
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    pre = -inf
    def isValidBST(self, root: Optional[TreeNode],left = -inf, right = inf) -> bool:
        def f(node):
            if node is None:
                return inf, -inf
            l_min, l_max = f(node.left)
            r_min, r_max = f(node.right)
            x = node.val
            if x <= l_max or x >= r_min:
                return -inf, inf
            return min(l_min,x), max(r_max,x)
        return f(root)[1] != inf
```

## 解题思路：
---
# 二叉搜索树：

**定义**：对于一个节点来说，它的左子树所有节点值都小于它的值，它的右子树所有节点值也都大于它的值，并且它的左子树和右子树也必须是二叉搜索树
![](assets/二叉树思路及不同题型/file-20260123171619465.png)
#### 先序遍历：
![](assets/二叉树思路及不同题型/file-20260123171619466.png)
1. 提出递归算法，除了传入节点还需要传入开区间范围，
2. 对于每个节点，先判断它的节点是否在开区间内，然后再往下递归
3. 如果往左边递归，那就把开区间的有边界更新为节点值，反之亦然
4. 先访问节点值，再递归左右子树的做法叫做前序遍历
5. 特别注意根节点（函数调用的入口），再往上它是没有节点的
#### 中序遍历：
![](assets/二叉树思路及不同题型/file-20260123171619466%201.png)
1. 如果按照左子树访问节点值，在递归右指数这样的顺序去遍历
2. 如果是二叉树搜索树，那么可以得到一个严格递增的数组，可以用数学归纳法从下往上证明
3. 如何判断严格递增？只需要比较相邻的元素，对于二叉搜索树来说：左子树->节点值->右子树这样的顺序遍历
4. 遍历完左指数，我们就可以看当前的节点值是否是大于上一个节点的值，然后把当前节点值记录下来和下一个节点值比大小
#### 后序遍历：
![](assets/二叉树思路及不同题型/file-20260123171619468.png)
1. 把节点值的范围往上传，对于5来说，它左子树的范围是[1,4]，右边是[6,6]，那么5大于左边的最大值，并且5小于右边的最小值，那这是合法的
2. 后序遍历需要先遍历左右子树，再判断节点值
**易错点**：看上去左边只需要返回一个最大值，右边只需要返回一个最小值，这是错误的
**因为**：如果把4改成6（这里为2的右子树），6大于5，如果只返回3（2的右子树中的最小值）的话，就无法比较6和5的大小了，所以最小值和最大值都需要返回
3. 如果中途发现不是一个二叉搜索树，可以额外返回一个False，或者返回负无穷到正无穷，上面的节点通过比较大小，会认为它不是一棵二叉搜索树
