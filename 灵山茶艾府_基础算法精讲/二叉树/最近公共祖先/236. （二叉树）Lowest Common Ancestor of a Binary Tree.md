## 参考答案
---
```python
 # Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None
  
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if root is None or root is p or root is q: ## 边界条件
            return root
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right: ## 当left 和 right返回都不为None时，返回root，只有在left为p或q的一个祖先，right为一另个祖先时，才会同时left 和 right 都不为None， left and right 为True（整个递归过程如果有的话只有一次）
            return root
        if left:
            return left
        return right
```

## 二叉树的最近公共祖先
分情况讨论：
![](assets/236.%20（二叉树）Lowest%20Common%20Ancestor%20of%20a%20Binary%20Tree/file-20260124120234777.png)
空节点直接返回空节点![](assets/236.%20（二叉树）Lowest%20Common%20Ancestor%20of%20a%20Binary%20Tree/file-20260124120234778.png)
不需要继续递归了，如果p是5，那么q不管是5下面哪个节点，最近公共祖先都是5，所以不需要继续递归了，直接返回5就可以
**注意**：如果q是8，答案是3，不会在5下面，无论如何，5下面都不要递归，返回5并不代表最终答案就是5
![](assets/236.%20（二叉树）Lowest%20Common%20Ancestor%20of%20a%20Binary%20Tree/file-20260124120234779.png)
左右子树都有，那么最近公共祖先就是当前节点
