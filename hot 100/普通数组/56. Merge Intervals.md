## 参考答案：

```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda p: p[0])  #按照每个区间的第一个元素（左端点）进行排序
        ans = []
        for p in intervals:
            if ans and p[0] <= ans[-1][1]:  # 可以合并
                ans[-1][1] = max(ans[-1][1], p[1])  # 更新右端点最大值
            else:  # 不相交，无法合并
                ans.append(p)  # 新的合并区间
        return ans
```
时间复杂度O(n logn) n为intervals的长度，瓶颈在排序上 
空间复杂度O(1)
先排左端点，再判断两两之间是否相交
