==pop、top 和 getMin 操作总是在 非空栈 上调用==
## 参考答案：
---
```python
class MinStack:
    def __init__(self):
        # 这里的 0 写成任意数都可以，反正用不
        self.st = [(0, inf)]  # 栈底哨兵
  
    def push(self, val: int) -> None:
        self.st.append((val, min(self.st[-1][1], val)))
  
    def pop(self) -> None:
        self.st.pop()
  
    def top(self) -> int:
        return self.st[-1][0]
  
    def getMin(self) -> int:
        return self.st[-1][1]
```
时间复杂度：所有操作均为 O(1)。
空间复杂度：O(q)。其中 q 是 push 调用的次数。最坏情况下，只有 push 操作，需要 O(q) 的空间保存元素
**注意**：
1. st一个元祖中的第一个元素存储当前元素的值，第二个元素存储当前最小值
2. 注意题目说操作总是在非空栈 上调用，那么可以使用哨兵（仅有哨兵属于空栈）
3. 如何维护最小值：==preMin[i]=min(preMin[i−1],nums[i])==
