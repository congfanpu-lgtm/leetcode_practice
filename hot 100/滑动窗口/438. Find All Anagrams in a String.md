## 参考答案：
---
```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        cnt_p = Counter(p)
        cnt_s = Counter()
        ans = []
  
        for right,c in enumerate(s):
            cnt_s[c] += 1
  
            left = right - len(p) + 1
            if left < 0:
                continue
            if cnt_s == cnt_p:
                ans.append(left)
  
            cnt_s[s[left]] -= 1
        return ans
```
**定长滑窗**。枚举 s 的所有长为 n 的子串 t，如果 t 的每种字母的出现次数，和 p 的每种字母的出现次数都相同，那么 t 是 p 的异位词。
