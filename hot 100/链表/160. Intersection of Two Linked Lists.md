## 参考答案：
---
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None
  
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        p,q = headA, headB
        while p is not q:
            p = p.next if p else headB
            q = q.next if q else headA
        return p
```
时间复杂度O(n^2)，空间复杂度O(1)
链表中的p和q存储的都是节点的引用（内存地址）

## 帮助理解：
---
![](assets/160.%20Intersection%20of%20Two%20Linked%20Lists/file-20260225150527922.png)
例子：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
其中A和B都有（仅仅是数值相同，内存地址不同），但是相交节点的值为8，是因为skipA = 2 skipB = 3，表示从第3和第四个元素开始有相同的内存地址。

在链表相交问题中，相交指的是同一个节点对象（相同的内存地址），而不是仅仅值相等。
