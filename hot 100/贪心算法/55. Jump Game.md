## 回答（正确）：

从后往前的遍历思路：
```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        n = len(nums)
        k = 1
        for _ in range(n):
            if n == 1:
                return True
            if nums[n - 1 - k ] >= k:
                n = n - k
                k = 1
            else:
                k += 1
        return False
```
## 参考答案：
---
灵神：
理解方式：把每个nums[i]看成闭区间 i 到 i+nums[i] ,问题变成判定这 n 个区间能否合并成一个大区间（而不是多个区间），思路参考[56. Merge Intervals](../普通数组/56.%20Merge%20Intervals.md) 
```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        mx = 0
        for i, jump in enumerate(nums):
            if i > mx:  # 无法到达 i
                return False
            mx = max(mx, i + jump)  # 从 i 最右可以跳到 i+jump
        return True
```
提前结束：
```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        mx = 0
        for i, jump in enumerate(nums):
            if i > mx:  # 无法到达 i
                return False
            mx = max(mx, i + jump)  # 从 i 最右可以跳到 i + jump
            if mx >= len(nums) - 1:  # 可以跳到 n-1
                return True
```
- 时间复杂度：O(n)，其中 n 是 nums 的长度。
- 空间复杂度：O(1)。
