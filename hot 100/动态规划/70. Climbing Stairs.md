## 参考答案：
----
递归+记忆化搜索：
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        @cache
        def dfs(i:int) -> int:
            if i <= 1:
                return 1
            return dfs(i - 1) + dfs(i - 2)
        return dfs(n)
```
时间复杂度：O(n)。由于每个状态只会计算一次，动态规划的时间复杂度 = 状态个数 × 单个状态的计算时间。本题状态个数等于 O(n)，单个状态的计算时间为 O(1)，所以动态规划的时间复杂度为 O(n)。
空间复杂度：O(n)。有多少个状态，memo 数组的大小就是多少。

递推：
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        f = [0] * (n+1)
        f[0] = f[1] = 1
        for i in range(2,n+1):
            f[i] = f[i - 1] + f[i - 2]
        return f[n]
```
空间复杂度优化：
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        f0 = f1 = 1
        for _ in range(2, n + 1):
            new_f = f1 + f0
            f0 = f1
            f1 = new_f
        return f1
```
时间复杂度：O(n)。
空间复杂度：O(1)。
