## 参考答案：
---
```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        f = [[1] * (i+1) for i in range(numRows)]
        for i in range(2, numRows):
            for j in range(1,i):
                # 左上方的数 + 正上方的数
                f[i][j]=f[i-1][j-1] +f[i-1][j]
        return f
```
- 时间复杂度：O(numRows2)。
- 空间复杂度：O(1)。返回值不计入

**注意**：
1. 杨辉三角的二维列表创建方式
