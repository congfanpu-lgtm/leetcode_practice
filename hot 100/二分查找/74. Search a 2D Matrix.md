做法一（二分）：
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        left, right = 0, m*n-1
        while left  <= right:
            mid = (left + right) // 2
            x = matrix[mid // n][mid % n] ## 非常妙的处理，变向的将矩阵变成数列
            if x == target:
                return True
            if x < target:
                left = mid + 1
            else:
                right = mid - 1
        return False
```
- 时间复杂度：O(log(mn))，其中 m 和 n 分别为 matrix 的行数和列数。
- 空间复杂度：O(1)。
注意要学习方法一中对于矩阵的处理方式 ： ==x = matrix[mid // n]  [mid % n] ==

做法二（排除法）：
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        i, j = 0, n - 1
        while i < m and j >= 0:  # 还有剩余元素
            if matrix[i][j] == target:
                return True  # 找到 target
            if matrix[i][j] < target:
                i += 1  # 这一行剩余元素全部小于 target，排除
            else:
                j -= 1  # 这一列剩余元素全部大于 target，排除
        return False
```
- 时间复杂度：O(m+n)，其中 m 和 n 分别为 matrix 的行数和列数。
- 空间复杂度：O(1)
