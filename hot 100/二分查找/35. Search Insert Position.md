## 回答：

```python
def lower_bound(nums:List[int], target: int)-> int:
    left = 0
    right = len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return left
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        return lower_bound(nums,target)
```
- 时间复杂度：O(logn)，其中 n 为 nums 的长度。
- 空间复杂度：O(1)，仅用到若干额外变量
