做法一（递归）：
```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        def dfs(node: Optional[TreeNode]) -> None:
            if node is None:
                return
            dfs(node.left)       # 左
            ans.append(node.val) # 根（这行代码移到前面就是前序，移到后面就是后序）
            dfs(node.right)      # 右
  
        ans = []
        dfs(root)
        return ans
```
- 时间复杂度：O(n)，其中 n 是二叉树的节点个数。
- 空间复杂度：O(h)，其中 h 是二叉树的高度。递归需要 O(h) 的栈空间。返回值不计入。

==补充：==
二叉树有三种常见的遍历方式：

前序遍历(**Preorder Traversal**)：根-左-右。先获取根节点值，再访问根的左子树，最后访问根的右子树。
中序遍历(**Inorder Traversal**：左-根-右。先访问根的左子树，再获取根节点值，最后访问根的右子树。
后序遍历(**Postorder Traversal**)：左-右-根。先访问根的左子树，再访问根的右子树，最后获取根节点值。
