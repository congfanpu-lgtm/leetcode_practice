```java
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        buy = [0] * n
        ans = inf
        profit = 0
        for i,x in enumerate(prices):
            if  x < ans:
                ans = x
            buy[i] = ans
  
        for i,x in enumerate(prices):
            p = x - buy[i]
            if profit < p:
                profit = p
        return profit
```

Neetcode
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        l, r = 0, 1
        maxprofit = 0 
        while r < len(prices):
            if prices[l] < prices[r]: ## 如果右指针比左指针大直接计算
                profit = prices[r] - prices[l]
                maxprofit = max(maxprofit, profit)
            else:  ## 右指针比左指针小那么 把左指针换到右指针这
                l = r
            r += 1
        return maxprofit
```
考点：
1. 双指针的运用
2. 一点小巧思，尽管指针往后走但是，最大利益保存了
