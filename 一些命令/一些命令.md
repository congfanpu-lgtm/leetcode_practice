nonlocal ans：表示 ans 是一个非局部变量，它既不是局部变量，也不是全局变量，而是闭包（外层函数）中的变量
在内层函数 `dfs` 中想要**修改**外层函数的 `ans` 变量，而不是创建一个新的局部变量
```python
def test():
    ans = 0
    def inner():
        nonlocal ans  # 声明 ans 是外层的变量
        ans = 1       # 修改外层的 ans
    inner()
    print(ans)  # 输出：1（被成功修改）
```
