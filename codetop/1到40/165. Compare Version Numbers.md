#### 参考答案：
---
```python
class Solution:
    def compareVersion(self, version1: str, version2: str) -> int:
        a = map(int, version1.split('.'))
        b = map(int, version2.split('.'))
        for ver1, ver2 in zip_longest(a,b, fillvalue = 0):
            if ver1 != ver2:
                return -1 if ver1 < ver2 else 1
        return 0
```
- 时间复杂度：O(n+m)，其中 n 是 version1​ 的长度，m 是 version2​ 的长度。
- 空间复杂度：O(n+m)
**注意**：
- ziplongest 可以在较短的迭代器耗尽时，用指定的fillvalue填充缺失的值
